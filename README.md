# Vehicle Fleet Monitoring System

A backend-focused vehicle fleet monitoring system built using Node.js, Express.js, PostgreSQL and JWT authentication.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- JWT
- bcrypt
- REST APIs
- Postman
- Git & GitHub

## Current Features

### Authentication

- User registration
- User login
- Password hashing with bcrypt
- JWT authentication
- Protected routes

### Vehicle Management

- Create vehicle
- Get all vehicles
- Get vehicle by ID
- Update vehicle
- Delete vehicle
